# Parchis

Proyecto Java con Maven.

## Abrir en Apache NetBeans

1. Clona el repositorio desde NetBeans o con `git clone`.
2. En NetBeans, selecciona **Archivo > Abrir proyecto** y elige la carpeta clonada que contiene `pom.xml`.
3. Usa un JDK 26 para compilar y ejecutar el proyecto.

La clase principal es `app.Main`.
